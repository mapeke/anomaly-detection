# Стенд упрощённой сети провайдера (GNS3 + MikroTik CHR)

Все атаки выполняются **только внутри стенда** (изолированная сеть GNS3, без выхода в Интернет).

## Топология (7 узлов)

```
                 [EXT-SRV 203.0.113.10]     [ATTACKER 198.51.100.66]
                          \                     /
                     ether2\                   /ether3
                        +---------------------------+
                        |  R-BORDER (CHR)           |  граница / «Интернет»
                        |  lo 10.255.0.1            |
                        +-------------+-------------+
                                      | ether1 10.0.12.0/30
                        +-------------+-------------+
                        |  R-CORE (CHR)             |  ядро + ЦОД провайдера
                        |  lo 10.255.0.2            |--- ether3 10.0.0.0/24  [ISP-SRV: DNS/WEB 10.0.0.53]
                        +-------------+-------------+
                                      | ether2 10.0.23.0/30
                        +-------------+-------------+
                        |  R-BNG (CHR)              |  доступ/агрегация, BNG, CGNAT
                        |  lo 10.255.0.3            |
                        +------+-------------+------+
                        ether2 |             | ether3
               [SUB-1 100.64.10.20]     [SUB-2 100.64.10.21]   абоненты (CGNAT 100.64.0.0/10)

  Коллектор: хост с docker compose, 10.0.0.100, UDP/2055 — получает NetFlow v9 / IPFIX
  от R-BORDER и R-BNG (экспорт с интерфейсов, обращённых к абонентам и к Интернету).
```

## План IP-адресации

| Сегмент | Сеть | Узлы |
|---|---|---|
| Loopback маршрутизаторов | 10.255.0.0/24 | R-BORDER .1, R-CORE .2, R-BNG .3 |
| R-BORDER — R-CORE | 10.0.12.0/30 | .1 / .2 |
| R-CORE — R-BNG | 10.0.23.0/30 | .1 / .2 |
| ЦОД провайдера | 10.0.0.0/24 | шлюз .1, DNS/WEB .53, коллектор .100 |
| Абоненты (CGNAT) | 100.64.10.0/24 | шлюз .1, SUB-1 .20, SUB-2 .21 |
| Внешний сервер | 203.0.113.0/24 | шлюз .1, EXT-SRV .10 |
| Хост атакующего | 198.51.100.0/24 | шлюз .1, ATTACKER .66 |
| Публичный пул CGNAT | 192.0.2.0/28 | на R-BNG |

Маршрутизация — OSPF area 0 между маршрутизаторами; адреса — из диапазонов документации
(RFC 5737) и CGNAT (RFC 6598), чтобы исключить пересечение с реальными сетями.

## Порядок развёртывания

1. GNS3 2.2+, образ MikroTik CHR 7.x (`chr-7.x.img`), образы Ubuntu 22.04 для хостов
   (на хостах: iperf3, curl, dnsutils; на ATTACKER — hping3, nmap, hydra).
2. Собрать топологию по схеме, коллектор подключить к R-CORE ether3 через облако/NAT-адаптер GNS3.
3. Применить конфигурации `mikrotik/*.rsc` (`/import file-name=r-border.rsc`).
4. На хосте коллектора: `docker compose up --build`, проверить приём: `docker compose logs loader`.
5. Фон: `scenarios/background.sh` на SUB-1/SUB-2 и EXT-SRV (не менее 1 ч записи нормы).
6. Атаки: `scenarios/run_attacks.sh` на ATTACKER — пишет журнал `attacks_journal.csv`
   (время начала и конца каждого сценария), который служит разметкой.
